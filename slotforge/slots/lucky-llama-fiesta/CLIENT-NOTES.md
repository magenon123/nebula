# Lucky Llama Fiesta client notes (kai)
Files: slot.json (bets/maxWin/anteCost/buys equal the engine CFG; text, loading, fever "Fiesta Luck", buys, intro/outro), slot.js (hooks), kai.css (client css; `python3 embed-kai.py` splices it after the `/* KAI */` marker of slot.css, art builds keep it). Smoke: `node slotforge/shell/smoke-lucky-llama.cjs`. Build: `python3 build-standalone.py lucky-llama-fiesta --server`. Test handle: `window.__ll`.
Design: 15 real `.cell`s in #grid (idx = reel*3+row, grid placement kept in inline style) + `#reels` (5 clipped strips of 15 cells: pad, 3 final, 8 spin-blur (`sb*`), 3 old). The strip scrolls with translate3d only; a simulated clock (`simT += dt / T()`) drives everything so turbo and the tap speed-up also shorten a spin that is already running. Stop times are solved (planNormal) so the 430 ms quadratic landing ends at the planned instant (900 ms + 220 ms per reel); tease reels (planTease) ramp down to a slow speed with a heartbeat + glow. At touch the real cells (same symbols) replace the strip and bounce 11 px.
Rounds: `baseSpin(R)` stores R; base/trigger spin -> lines (callout plate #coLine "LINE 7 - 3x TACO - $2.50", thick colored path layer, `.cell.hit` via FX.act, others dim `#grid.focus`, wild cells ring `.wl`); more than 3 winning lines: top 2 singly, the rest grouped. Link = shell bonus loop over `bonus.spins` (respins), cracks inside the LAST respin (pays the total through ctx.onWin). Parade = free spins; sticky wilds stay as real cells (class `sticky top`) above the strips; ladder `#ladder.m<step>`; Collector grabs are NOT multiplied; there is NO character beside the board (owner revise): a grab = gold ring + coin burst on the piñata cell and the plate "COLLECTOR GRABS +$x (no multiplier)"; #pdCollector is hidden by css (only full-screen splashes show the llama). Class `pop` is the shell's floating-pill class: never put it on art plates, kai.css uses `bump`.
Pace (default speed): spin 0.9 s + 0.22 s/reel, line 0.9 s each, group 1.25 s, respin ~1.8 s, crack 0.36 s (0.26 s when > 9), ladder callout 1.5 s.
Portrait: cfg.portrait is tuned at runtime (tunePortrait in init): 45 px padding on tall phones (board about 89 percent of the width), more on short phones/tablets so the logo + ladder bar + jackpot row stack above the board never overlaps the buy sign. The ladder is rotated 90 degrees into a horizontal bar (labels counter-rotated). Zoomed plates (zoom:z) need left/top = target / z. `#ga` is moved down by gy + 165 (half of the 330 units the stack adds above the board).
Gotchas: never `style.cssText=''` on cells (it wipes the grid placement; use resetCells); the shell's `pop` class; audio makes headless Chromium very slow, so the smoke test checks sound recipes last in their own page; `pkill -f smoke-lucky` matches its own shell, use `pkill -f "[s]moke-lucky"`.
Smoke: `node slotforge/shell/smoke-lucky-llama.cjs [--only line,tease,link,parade,buy,speed,portrait,sound]` (about 9 min in full; HB=1 prints a heartbeat).
